## Why

识谱入门用户（谱都认不全的人）需要一个专注「看谱 → 找键」的反复练习工具。参考产品「口袋五线谱」的单音练习验证了这种练法有效，但它带有广告、登录、积分等干扰。本项目做一个简洁版，先在安卓手机上以网页形式运行，最小化开发，只实现初级常用 5 组的单音练习闭环。

## What Changes

- 新建一个 Web 应用（Vite + TypeScript），在安卓手机浏览器中运行；后续可装成 PWA 或用 Capacitor 打包成 APK，代码不变。
- 音符数据：内置 88 键全部 52 个白键的数据表（中文组名记法、国际记法、所在组、谱号），练习分组以「数据 + 筛选条件」定义。
- 分组选择：提供初级 / 中级 / 高级三个页签；MVP 只开放初级「常用音符」5 组（大字组、小字组、小字一组、小字二组、小字三组），其余分组显示为「即将推出」。
- 练习配置：结束方式支持「默认模式」（该组每个音各考一次）和「数量练习」（做满 N 题，可重复）；通用设置支持「随机顺序」「显示音符名称」。
- 练习页：
  - 谱面照搬参考产品：一次显示整行谱，4/4 拍，随机四分 / 二分 / 全音符凑满小节，最后一小节可以不满，只考音高；当前题用蓝底高亮。
  - 一个八度的钢琴键盘，键上可显示中文记法音名（带上标组号）。
  - 出题时不播放目标音；按下任意键时播放该键的音（点错也播放）。
  - 点错时停在原题等重试，这题记为错；点对后进入下一题；最后一题点对后自动进入结果页。
  - 💡 提示：高亮正确的键，这题记为错，然后等用户点这个键。
  - 顶部显示题号和正计时，对错用绿色 / 红色提示条反馈。
- 结果页：正确率、星级、正确题数、错误题数、用时（秒，保留 3 位小数）、错题集（「第 N 题：正确答案是 a1，但是选择了 b1」），以及「再来一次」和「返回」。
- 练习记录：每次练习保存到本地（逐题记录目标音、点过的键、是否用了提示、反应时间）；练习中心显示累计「练习数量 / 练习场次 / 准确率」；提供历史记录列表。
- 不做：中级、高级和「其他音符」分组；限时练习和组合练习；MIDI 输入；错题本；自定义练习；课程、工具、登录、积分、排行榜、广告。

## Capabilities

### New Capabilities

- `note-catalog`: 52 个白键的音符数据表、中文 / 国际记法换算、谱号规则，以及练习分组预设（难度 → 分类 → 分组 → 筛选条件）。
- `practice-session`: 练习配置（结束方式、通用设置）、出题、单题判定状态机（点错重试、提示、计分）、按键发声和计时。
- `staff-rendering`: 整行五线谱的生成与绘制：随机节奏凑小节、分行、谱号、加线、符干方向、当前题高亮。
- `piano-keyboard`: 一个八度的触屏钢琴键盘：按下反馈、音名显示、提示高亮、手机触屏适配。
- `practice-history`: 结果页、星级规则、本地保存练习记录、累计统计和历史记录列表。

### Modified Capabilities

（无，这是项目的第一个 change）

## Impact

- 新增前端项目代码（仓库目前只有 `openspec/`）。
- 新增依赖：`vite`、`typescript`、`vexflow`（五线谱排版），测试用 `vitest`。
- 新增静态资源：钢琴采样音频（使用 CC-BY 授权的 Salamander Grand Piano，打包在应用内，需在「关于」中注明来源）。
- 数据只存在手机浏览器本地（`localStorage`），不需要后端和账号。
