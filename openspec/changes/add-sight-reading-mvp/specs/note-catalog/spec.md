## ADDED Requirements

### Requirement: 白键音符目录

系统 SHALL 内置 88 键钢琴全部 52 个白键的音符目录，每个音符包含：MIDI 编号、国际记法（如 `C4`）、中文记法（如 `c1`）、所在八度组（大字二组 / 大字一组 / 大字组 / 小字组 / 小字一组 / 小字二组 / 小字三组 / 小字四组 / 小字五组）、音区（低 / 中 / 高）、谱号、常用标记（`C2`–`B6` 为常用）。

#### Scenario: 目录覆盖完整

- **WHEN** 读取音符目录
- **THEN** 目录包含 52 个白键音符，覆盖 A0–C8，且每个八度组恰好 7 个音（大字二组 2 个、小字五组 1 个）

#### Scenario: 记法一致性

- **WHEN** 查询中央 C
- **THEN** 国际记法为 `C4`，中文记法为 `c1`，所在八度组为小字一组，谱号为高音谱号

### Requirement: 谱号分配规则

系统 SHALL 按以下规则为音符分配谱号：MIDI 编号 ≤ B3（59）用低音谱号，≥ C4（60）用高音谱号。

#### Scenario: 谱号分界

- **WHEN** 分别查询 B3 和 C4
- **THEN** B3 分配低音谱号，C4 分配高音谱号

### Requirement: 中文记法展示

系统 SHALL 展示中文记法时用上标数字表示组号（`c¹`、`d¹`、`C`、`c2`），大字组用大写字母、小字组用小写字母、小字一组及以上用小写字母加组号。

#### Scenario: 键盘音名显示

- **WHEN** 小字一组练习且「显示音符名称」开启
- **THEN** 键盘白键依次显示 `c¹ d¹ e¹ f¹ g¹ a¹ b¹`

### Requirement: 练习分组预设

系统 SHALL 以数据 + 筛选条件的形式定义练习分组预设，结构为：难度（初级 / 中级 / 高级）、分类、组名、描述、音符筛选条件、预计题数。初级页签含 2 个分类：「常用音符」5 组（大字组、小字组、小字一组、小字二组、小字三组，每组 7 个音）、「其他音符」4 组（大字二组、大字一组、小字四组、小字五组）；中级页签含「常用音区」1 组、「音区练习」3 组（低/中/高音区）、「分组练习」3 组（下加线/中间线/上加线）；高级页签含「全音区」1 组。

#### Scenario: 初级常用 5 组

- **WHEN** 选择初级 / 常用音符 / 小字一组
- **THEN** 筛选出 7 个音符（C4–B4），默认模式生成 7 题

#### Scenario: 未实现分组不可用

- **WHEN** 查看「其他音符」及中级、高级页签下的分组
- **THEN** 显示分组信息但标记「即将推出」，不能开始练习

#### Scenario: 新增分组零代码

- **WHEN** 以新的筛选条件（如：谱号=低音 且 谱表位置=谱表内）新增一条分组预设
- **THEN** 无需修改判定或渲染逻辑即可开始该组练习
